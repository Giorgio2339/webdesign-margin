Signature Visual Art Direction

MARGIN. — Hero Right Half — Nur Plan, kein Code

01 — Layout

Der Hero bleibt full-width, 100vh sticky. Die Teilung ist 50 / 50 auf einem unsichtbaren vertikalen Schnitt bei 50vw. Links bleibt der bestehende Content (Headline, Copy, CTA). Rechts entsteht das Signature Visual als eigenständiger <div class="hero-signature"> mit position: absolute; right: 0; top: 0; width: 50%; height: 100%. Kein Overlap mit dem Zoom-Wordmark — das Signature Visual faded beim Scroll-Zoom aus (opacity 1→0 in den ersten 10% des ScrollTrigger).

02 — SVG-Aufbau

Ein einziger Inline-SVG-Container, viewBox="0 0 800 800", zentriert im rechten Halb-Container. Drei semantische Layer als <g>-Gruppen:

Layer 1 — Structural Grid. Vertikale und horizontale Linien (stroke-width: 0.5px, weiß bei 8% Opacity). Bildet ein 8×8-Raster. Zwei Diagonalachsen kreuzen sich im Zentrum. Vier Registrierungskreuze (je 12px) an den Ecken eines inneren Quadrats. Zwei konzentrische Kreise (r=120, r=200) mit gestricheltem Stroke (stroke-dasharray: 2 6). Messlinien mit kleinen Endstrichen an Ober- und Unterkante des Wortbereichs.

Layer 2 — Construction Lines. Baseline, Cap-Height, x-Height und Descender-Linie des Worts, durchgehend, stroke-width: 0.75px, weiß bei 15% Opacity. Vertikale Guides an den Rändern jedes Buchstabens. Horizontale Mittellinie in Dark Cherry (#7A3040, 60% Opacity) — die einzige farbige Linie im Ruhezustand.

Layer 3 — Typografie. Das aktive Wort als <text>-Element in Instrument Serif, ~72px, weiß. Jeder Buchstabe in ein eigenes <tspan> gewrappt (für individuelle Transformation). Position: optisch zentriert auf dem Kreuzungspunkt der beiden Diagonalen.

03 — Idle Motion

Zwischen den Wortwechseln lebt das Grid subtil. GSAP-Timeline auf repeat: -1:

Die Registrierungskreuze rotieren mit 0.08°/s. Die gestrichelten Kreise verschieben ihren stroke-dashoffset kontinuierlich (30s Loop). Die Messlinien-Endstriche pulsieren in der Opacity zwischen 0.06 und 0.14 (4s Sinus). Die vertikalen Buchstaben-Guides atmen: scaleY 1.0→1.04→1.0 über 6s. Alles ease sine.inOut, bewusst langsam — das Grid wirkt lebendig, nicht nervös.

04 — Worttransition — die Choreografie

Fünf Phasen, Gesamtdauer 1.8s. Jeder Buchstabe des alten Worts ist ein eigenständiger Actor.

ZeitPhaseWas passiert
0 – 0.35s DECONSTRUCT Jeder Buchstabe bewegt sich auf einer eigenen Achse vom Zentrum weg. Ungerade Buchstaben nach oben + leichte Rotation (±3–8°), gerade nach unten. opacity 1→0.3. Gleichzeitig: die Construction Lines (Baseline, Cap-Height) brechen auf — sie fahren horizontal auseinander via clipPath (inset(0 50% 0 50%) → inset(0 0 0 0) invertiert). Ease: power3.in
0.35 – 0.70s DISSOLVE Buchstaben faden auf opacity 0. Gleichzeitig erscheinen an ihren letzten Positionen kurze Linien-Fragmente (je 2–4 Striche, weiß, 0.5px) — die Typografie zerfällt in architektonische Striche. Die Cherry-Mittellinie pulst einmalig auf volle Opacity und zurück auf 60%.
0.70 – 1.10s ARCHITECTURAL Nur Linien sichtbar. Die Fragmente gleiten auf die Construction Lines zu und docken an — sie werden Teil des Grids. Neue vertikale Guides erscheinen (scaleY: 0→1) an den Positionen der neuen Buchstaben. Registrierungskreuze drehen sich kurz schneller (0.5°/frame für 0.4s). Grid-Linien blitzen bei 15% Opacity auf.
1.10 – 1.50s REALIGN Construction Lines (Baseline, Cap-Height) fahren wieder zusammen via clipPath-Animation. Die neuen Buchstaben-Guides stehen. Cherry-Mittellinie stabilisiert sich. Ein kurzer scale(1.01→1.0)-Impuls auf dem gesamten Grid signalisiert das Einrasten.
1.50 – 1.80s MATERIALIZE Neues Wort erscheint Buchstabe für Buchstabe (Stagger: 0.04s). Jeder Buchstabe: opacity 0→1, y: ±8px→0, rotation: ±2°→0. Ease: power2.out. Erst nach dem letzten Buchstaben setzt die Idle Motion wieder ein.
Die Fragmente in Phase 2 werden nicht per Hand gezeichnet. Jeder Buchstabe generiert 2–4 <line>-Elemente an seinen Extrempunkten (getBBox). Nach Phase 3 werden sie via GSAP .kill() entfernt.

05 — Timing

Gesamtzyklus pro Wort: 5s. Davon 3.2s Hold (Idle Motion sichtbar) + 1.8s Transition. Reihenfolge: MARGIN. → DESIGN → BRANDING → DIGITAL → IDENTITY → Loop. Beim initialen Page Load startet MARGIN. ohne Transition, erster Wechsel nach 4s.

06 — Farblogik

Weiß (rgba(255,255,255, 0.08–1.0)): Alles Strukturelle — Grid, Guides, Messlinien, Kreise, Typografie. Opacity-Abstufungen erzeugen Tiefe ohne Grautöne. Typografie bei 100%, Structural Grid bei 6–10%, Construction Lines bei 12–18%.

Dark Cherry (#7A3040 bei 40–60% Opacity): Exakt zwei Elemente — die horizontale Mittellinie und die Endstriche der Messlinien. Kein Fill, kein Glow, keine Fläche. Cherry taucht nur als Linie auf. Während der Transition pulst die Mittellinie kurz auf 90% — das einzige Moment, in dem Farbe dominant wird.

07 — Responsive

Ab ≤960px: Das Signature Visual rückt unter den Hero-Text, wird width: 100%; height: 50vh. Der SVG-viewBox bleibt gleich, skaliert via preserveAspectRatio="xMidYMid meet". Ab ≤600px: Wortgröße im SVG reduziert auf ~48px. Construction Lines und Messlinien bleiben, aber die äußeren Grid-Linien (Reihen 1,2,7,8) werden via display:none entfernt — das Grid wird dichter, nicht kleiner. Die Idle Motion bleibt identisch. Die Transition-Dauer bleibt 1.8s. Bei prefers-reduced-motion: Idle stoppt, Wortwechsel wird ein simpler Crossfade (0.6s).

08 — Implementierungsplan

Schritt 1 — SVG-Markup in index.html einfügen. Neuer Container .hero-signature innerhalb .section-hero, nach .hero-zoom-content. Inline-SVG mit den drei Layer-Gruppen. Buchstaben-<tspan>-Struktur für das erste Wort (MARGIN.).

Schritt 2 — CSS in style.css. Positionierung des Containers (absolute, rechte Hälfte). Responsive-Breakpoints. Basisfarben der SVG-Elemente über CSS Custom Properties. will-change: transform, opacity auf die animierten Gruppen.

Schritt 3 — GSAP Idle Motion in main.js. Eigene Timeline signatureIdleTl, repeat: -1, paused: true. Wird nach Loader-Completion gestartet. Nutzt bestehende GSAP-Instanz, kein zusätzlicher Import.

Schritt 4 — Wortwechsel-Engine. Array der fünf Wörter. Funktion transitionWord(oldWord, newWord) baut eine GSAP-Timeline mit den fünf Phasen. setInterval alle 5s ruft die nächste Transition auf, pausiert Idle, spielt Transition, resumed Idle. getBBox() liefert die Fragmentpositionen. clipPath-Animationen auf den Construction Lines via GSAP attr-Plugin.

Schritt 5 — Scroll-Integration. Im bestehenden Hero-ScrollTrigger: .hero-signature faded in den ersten 10% auf opacity: 0 (parallel zum Zoom). Unterhalb Viewport: Idle und Wechsel laufen unsichtbar weiter (kein Kill nötig, SVG ist lightweight).

Kein Code wurde verändert. Dieser Plan ist die verbindliche Grundlage für die Implementierung.
